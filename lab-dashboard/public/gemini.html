1. HTTP vs HTTPS: บนมือถือเปิดผ่าน https://homelab.tail285279.ts.net (มีกุญแจเขียว SSL จาก Let's Encrypt / Tailscale) เบราว์เซอร์จึงอนุญาตให้ใช้ไมค์ได้ แต่บน PC หากเข้าผ่าน HTTP ธรรมดา (เช่น http://... หรือ Port 8090) เบราว์เซอร์จะบล็อกไมโครโฟนเด็ดขาดตามมาตรฐานความปลอดภัย
2. สิทธิ์ระดับ Windows OS: บน Windows 10/11 หากปิดตัวเลือก "Let desktop apps access your microphone" เบราว์เซอร์จะไม่สามารถรับเสียงได้

💻 ตรวจสอบสิทธิ์ไมค์บน Windows PC (หากเปิด HTTPS แล้วยังไม่ได้ยิน)
1. ไอคอนแม่กุญแจหน้า URL: คลิกไอคอนรูปตัวปรับแต่งหรือแม่กุญแจหน้า URL บนเบราว์เซอร์ แล้วเลือก Microphone → Allow (อนุญาต)
2. Windows Privacy: เปิด Settings → Privacy & security → Microphone ตรวจสอบว่าเปิด "Microphone access" และ "Let apps access your microphone" เป็น On
3. หากใช้ Brave Browser: เข้า brave://settings/extensions แล้วเปิด "Use Google services for speech recognition"
💡 วิธีแก้ไขที่ 3: ปลดล็อก HTTP สำหรับ IP นี้ใน Chrome / Edge
หากต้องการสั่งงานด้วยเสียงบน HTTP (พอร์ต 8090) โดยตรง:
1. เปิดแท็บใหม่ใน Chrome พิมพ์: chrome://flags/#unsafely-treat-insecure-origin-as-secure
2. ตรงช่องว่าง ให้ใส่: http://192.168.1.123:8090
3. เลือกเมนูเป็น Enabled แล้วกดปุ่ม Relaunch
