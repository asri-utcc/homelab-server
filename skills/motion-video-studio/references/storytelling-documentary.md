# Storytelling Documentary Style (แนวเล่าเรื่อง 9:16 แบบ The Story Room)

สไตล์วิดีโอเล่าเรื่องแนวสารคดีสั้นสำหรับ TikTok / Reels / YouTube Shorts (30–90 วินาที, `1080x1920`, `30 fps`) เน้นเล่าเรื่องกระชับ น่าติดตาม มีหลักฐานภาพประกอบ แผนที่ และซับไตเติลอ่านง่าย

## โครงสร้างบทเล่าเรื่อง (Narrative Blueprint)

| ช่วง | สัดส่วนเวลา | เป้าหมาย | ตัวอย่างจังหวะเล่า |
| :--- | :--- | :--- | :--- |
| **1. Hook (เปิดเรื่อง)** | 0–5 วินาที (~10%) | หยุดนิ้วคนดูทันทีด้วยคำถามหรือความจริงชวนสงสัย | *"รู้ไหม? แสงแดดบนหลังคาบ้าน กลายเป็นไฟเปิดแอร์ได้ยังไงในพริบตา!"* |
| **2. Context / Start (จุดเริ่มต้น)** | 5–15 วินาที (~20%) | ปูพื้นฐานว่าเริ่มจากตรงไหน เห็นภาพรวมหรือพิกัดแผนที่ | ชี้จุดเริ่มบนแผนที่ / ผังระบบ พร้อมป้ายชื่อชัดเจน |
| **3. Mechanism / Body (เนื้อหาหลัก 2–4 ขั้น)** | 15–45 วินาที (~50%) | เล่าเป็นลำดับขั้น (Step 1 → 2 → 3) เปลี่ยนภาพ/การ์ดทุก 4–7 วินาทีไม่ให้แช่นิ่ง | การ์ดภาพเด้งขึ้นมาพร้อมเครดิต หรือแผนภาพไหลตามเส้นทาง |
| **4. Climax / Endpoint (จุดจบ/ผลลัพธ์)** | 45–55 วินาที (~15%) | สรุปว่าสุดท้ายไปจบที่ไหน และเกิดประโยชน์อะไรกับคนดู | สรุปภาพรวมทั้งระบบ + ตัวเลข/ผลลัพธ์สำคัญ |
| **5. CTA / Hold (ปิดท้าย)** | 3–5 วินาทีสุดท้าย (~5%) | ทิ้งท้ายกระชับ ชวนคิดหรือคอมเมนต์ พร้อม Hold frame นิ่ง | *"แล้วที่บ้านคุณติดโซล่าเซลล์หรือยัง? คอมเมนต์มาคุยกันได้!"* |

## หน้าตา (Visual Spec)
- **ชุดสี (2 โทนเลือกตามหัวข้อ):**
  - **Editorial Documentary Dark (สารคดี/ประวัติศาสตร์/สถานที่):** พื้นหลังแผนที่เข้ม `#0F172A`–`#1E293B`, หัวข้อขาว `#FFFFFF` สลับคำเน้นเหลืองอำพัน `#FACC15`, กรอบการ์ดภาพสีขาว `#FFFFFF` ขอบหนา 8–10px พร้อมเงาตกกระทบ, ป้ายเครดิตมุมล่างขวา `rgba(15,23,42,0.75)`
  - **Clean Explainer Light (เทคโนโลยี/วิทยาศาสตร์/ระบบ):** อ้างอิง `look-21` Isometric Flow — พื้นหลังขาวนวล `#EEF2F7` → `#E3E9F1`, ตัวอักษรหินชนวนเข้ม `#1E293B`, สีเน้นแยกตามขั้นตอน (`#36C39A`, `#3B6CF6`, `#FF6A4D`, `#F59E0B`)
- **ตัวอักษร (Typography):**
  - หัวข้อบน: `Noto Sans Thai Bold` / `Noto Looped Thai Bold` ขนาด `64–76px`, `lineHeight: 1.3`, แยกสีคำสำคัญ (Keyword highlight)
  - ซับไตเติล: `Noto Sans Thai Bold` ขนาด `44–52px`, จัดกลาง, พื้นหลัง pill กึ่งโปร่งแสงหรือขอบ stroke หนา + drop-shadow อ่านชัดบนทุกพื้นหลัง
  - ป้ายเครดิตภาพ: `22–24px` ระบุแหล่งภาพจริงเสมอ (เช่น `Photo: Wikimedia Commons`)
- **การจัดวาง Safe Zone (1080×1920):**
  - **Top safe margin:** เว้นด้านบนอย่างน้อย `150px` (หลบแถบสถานะ/ปุ่ม UI ของ TikTok/Reels)
  - **Right safe margin:** เว้นขอบขวาช่วงกลาง-ล่าง `130px` (หลบปุ่ม Like/Comment/Share)
  - **Bottom safe margin:** เว้นด้านล่างอย่างน้อย `240px` สำหรับซับไตเติลและแถบชื่อช่อง/คำอธิบาย
  - **Visual stage:** กึ่งกลางจอ `y: 340px – 1320px` เป็นพื้นที่แผนที่ การ์ดภาพ หรือแผนภาพเคลื่อนไหว

## การเคลื่อนไหว (Motion Choreography)
- **Ken Burns เบาๆ** บนภาพพื้นหลัง/แผนที่ (ซูมช้า 1.0 → 1.08 ตลอดซีน ห้ามนิ่งสนิท)
- **Photo Card Pop:** การ์ดภาพกรอบขาวเอียง `-2.5°` หรือ `+2.5°` เด้งขึ้นด้วยสปริง (`damping: 14, stiffness: 160`) พร้อมเสียง `sfx_pop.wav`
- **Scene Cut / Transition:** เปลี่ยนซีนทุก 5–9 วินาที ด้วยจังหวะ scale/wipe คมๆ พร้อม `sfx_whoosh.wav`
- **Active Subtitle Sync:** คำหรือท่อนที่กำลังพูดเปลี่ยนสีไฮไลต์ตามเวลาจริงจาก `timeline.json`

## สิ่งที่ควรเลี่ยง (Anti-Patterns)
- ❌ อย่าให้ข้อความยาวเกิน 2 บรรทัดต่อซับ 1 ก้อน (แบ่งท่อนละ 25–42 ตัวอักษรไทย)
- ❌ อย่าปล่อยภาพนิ่งแช่นานเกิน 6 วินาทีโดยไม่มีการเคลื่อนไหวขององค์ประกอบหรือกล้อง
- ❌ อย่าใส่ BGM ดังกลบเสียงพูด (ต้อง duck BGM ลงประมาณ `-18 dB` ถึง `-22 dB` เสมอ)
- ❌ อย่าให้สระบน/วรรณยุกต์ไทย (ิ ี ึ ื ่ ้ ๊ ๋) ชนขอบกล่องหรือโดน `overflow: hidden` ตัดขาด — ต้องมี `paddingTop` และ `lineHeight >= 1.35` เสมอ
